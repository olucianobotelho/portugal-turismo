Frontend Guidelines - Aplicativo de Turismo em Portugal
Este guia estabelece os padrões visuais e de design para o aplicativo de turismo em Portugal, garantindo consistência e uma experiência de usuário de alta qualidade.

Tipografia
Hierarquia de fontes

Títulos principais: Montserrat Bold (700), 24-32px

Subtítulos: Montserrat SemiBold (600), 18-22px

Corpo de texto: Open Sans Regular (400), 16px

Texto secundário: Open Sans Light (300), 14px

Destaques/Call-to-action: Playfair Display (600), 20px

Configuração

Espaçamento entre linhas: 1.5 para corpo de texto, 1.3 para títulos

Kerning: -0.5px para títulos grandes

Importar de Google Fonts (disponíveis para web e mobile)

Paleta de Cores
Cores primárias

Vermelho português: #D03023 (ações principais, alertas)

Verde português: #006633 (confirmaçōes, sucesso)

Azul marítimo: #0077B6 (links, elementos interativos)

Cores secundárias

Amarelo dourado: #FFBA08 (destaques, promoções)

Azul azulejo: #1A85FF (elementos de navegação, ícones)

Terracota: #CB8D73 (elementos culturais, gastronomia)

Cores neutras

Branco calcário: #F7F7F2 (fundos, cards)

Cinza pedra: #8D99AE (textos secundários)

Preto oliva: #2B2D42 (textos principais)

Cinza claro: #E5E5E5 (separadores, bordas)

Aplicação de acessibilidade

Contraste mínimo de 4.5:1 para texto sobre fundos

Indicadores visuais não dependentes apenas de cor

Modo escuro disponível para todas as telas

Espaçamento e Layout
Sistema de Grid

Grid de 12 colunas

Gutters: 16px (mobile), 24px (tablet), 32px (desktop)

Margens laterais: 16px (mobile), 32px (tablet), 64px (desktop)

Escala de espaçamento (baseada em Tailwind)

xs: 4px (0.25rem)

sm: 8px (0.5rem)

md: 16px (1rem)

lg: 24px (1.5rem)

xl: 32px (2rem)

2xl: 48px (3rem)

Breakpoints responsivos

Mobile: 320px - 639px

Tablet: 640px - 1023px

Desktop: 1024px e acima

Containers e cards

Raio de borda: 8px (padrão), 16px (cards grandes)

Sombras: 3 níveis de elevação (leve, média, alta)

Padding interno: 16px (padrão), 24px (áreas de conteúdo)

Biblioteca de UI
Framework principal

Tailwind CSS para estilização base

Componentes customizados usando Headless UI

Framer Motion para animações e transições

Componentes essenciais

Cards informativos para atrações turísticas

Bottom sheet para detalhes de POI (Pontos de Interesse)

Carrosséis para imagens e cards horizontais

Modal de filtros com animação de entrada suave

Bottom navigation fixo para mobile

Sistema de formulários

Inputs com validação visual

Autocomplete para busca de destinos

Datepickers customizados para reservas

Sliders para seleção de preço e distância

Sistema de Ícones
Biblioteca principal

Phosphor Icons (estilo regular)

Tamanhos: 16px (interface), 20px (navegação), 24px (destaques)

Ícones específicos de turismo

Conjunto customizado para POIs portugueses

Categorias: Monumentos, Praias, Vinícolas, Restaurantes, Miradouros

Formato SVG com possibilidade de colorização dinâmica

Aplicação

Consistência no estilo e peso visual

Rótulos de texto acompanhando ícones em navegação principal

Área de toque mínima de 44x44px para ícones interativos em mobile

Esta documentação de design frontend deve ser implementada em conjunto com o stack tecnológico especificado, utilizando React/Next.js para web e React Native para aplicativos móveis, garantindo uma experiência visual coesa e autenticamente portuguesa.
