# Turismo Portugal

Um site de turismo sobre Portugal, destacando destinos populares, gastronomia, experiências únicas e ferramentas para planejar sua viagem.

## 🌟 Características

- **Destinos Populares**: Explore os lugares mais visitados de Portugal, como Lisboa, Porto, Algarve e Madeira.
- **Experiências Únicas**: Descubra experiências autênticas como passeios de barco pelo Douro, roteiros gastronômicos e trilhas nos Açores.
- **Planejador de Viagem**: Ferramenta interativa para criar seu roteiro personalizado.
- **Gastronomia**: Conheça os pratos típicos e vinhos de cada região.
- **Busca**: Encontre facilmente informações sobre qualquer aspecto de sua viagem.

## 🛠️ Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## 🚀 Como executar

1. Clone o repositório
   ```bash
   git clone https://github.com/olucianobotelho/portugal-turismo.git
   ```

2. Instale as dependências
   ```bash
   npm install
   ```

3. Execute o servidor de desenvolvimento
   ```bash
   npm run dev
   ```

4. Abra [http://localhost:3000](http://localhost:3000) em seu navegador.
